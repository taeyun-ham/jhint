# jhint.kr 없는 주소를 진짜 404로 (2026-11-25)

- 계기: 사용자 Google Search Console 화면(2026-11-25 16:26) — https://jhint.kr/oem-vs-odm "페이지 색인을 생성할 수 없음: Soft 404"
- 같은 날 #230 보고(16:02 회신)의 "범위 밖 결정 2건" 중 soft 404

## 원인
- wrangler `not_found_handling: "single-page-application"` → 없는 주소에 홈(dist/index.html)을 200으로 보냄
- 구글은 "200인데 내용이 없는 페이지"로 보고 Soft 404, Bing은 홈과 같은 제목으로 봄
- /oem-vs-odm은 이 저장소에 있던 적 없는 주소(옛 가이드는 /guides/oem-vs-odm → 301 처리 중)

## 바꾼 것
- `wrangler.jsonc`: `not_found_handling: "404-page"` → 없는 주소는 `dist/404.html`을 **404 상태**로
- `scripts/prerender.mjs`: NotFoundPage를 `dist/404.html`로 만듦(robots noindex,follow, canonical·og:url·schema 없음)
- `NotFoundPage`: 경로를 `window.location.pathname` 대신 `'/404'` 고정(서버 렌더에 window 없음)

## 확인(로컬 wrangler dev :8791)
- 18페이지 200, 옛 가이드 8개 301, 키 파일·sitemap·robots 200
- /no-such-page, /oem-vs-odm, /guides/no-such → 404 + "Page Not Found" 화면
- /api/inquiry 응답은 운영과 같음

## 범위 밖(그대로)
- 끝 슬래시(/about/) 307 — Cloudflare html_handling 동작
